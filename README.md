# 어쩌다 농부 · 고구맙습니다

태안에서 어쩌다 농부가 된 부부의 이야기와 첫 고구마를 소개하는 한국어 원페이지 웹사이트입니다. Supabase에 주문을 저장하고 관리자 화면에서 재고와 배송을 관리합니다.

[판매 페이지](https://eojjeoda-farmer-gogumap.silver-lynx-2417.chatgpt.site/) · [농장 관리](https://eojjeoda-farmer-gogumap.silver-lynx-2417.chatgpt.site/admin.html)

## 실행

설치·빌드 없이 정적 서버에서 실행합니다. 이미지와 스타일은 HTML에 내장되어 있으며, 온라인 주문·로그인은 인터넷 연결이 필요합니다.

```sh
python3 -m http.server 8000
```

`http://localhost:8000`을 여세요. 배포할 때는 아래 여섯 파일을 같은 폴더에 함께 올립니다.

- `index.html`: 브랜드 이야기, 상품, 주문서
- `customer.js`: 상품 조회·할인 확인·주문서 확인·실제 접수
- `admin.html`, `admin.js`: 관리자 로그인, 주문·배송·재고 관리
- `farmer-api.js`: Supabase 통신과 관리자 세션
- `farmer-config.js`: 프로젝트 URL과 공개 publishable key

## 주문과 재고

- 호풍미 혼합 2kg 10,000원 / 5kg 20,000원, 기본 선택 5kg
- 주문당 배송비 3,500원, `GOGUMA` 주문당 2,000원 할인
- 가격·할인·수량은 서버에서 검증합니다.
- 접수 → 확정 → 배송 중 → 배송 완료. 확정할 때 중량 × 수량만큼 재고를 차감합니다.
- 배송 전 취소 시 확정 때 차감한 재고를 복구합니다. 접수만 된 주문은 재고를 차감하지 않습니다.
- 재고 입고·조정과 변경 사유, 발송 정보, 배송 완료 일시를 기록합니다.

결제, 입금 확인, 택배사 자동 배송 추적, 문자·메일 주문 알림은 연결하지 않았습니다. 관리자가 상태를 직접 처리합니다.

## 관리자와 개인정보

관리자는 Supabase Auth에서 이메일을 확인한 계정 중 비공개 허용 목록에 등록된 계정만 가능합니다. 비밀번호와 로그인 세션은 코드에 넣지 않습니다. 브라우저의 공개 키로 주문 조회나 재고 변경은 할 수 없습니다.

공개 데이터베이스 테이블의 직접 접근은 모두 차단했습니다. 공개 RPC는 상품/금액 조회와 주문 접수만 허용하고, 관리자 RPC는 서버에서 이메일 인증과 허용 목록을 검사합니다. 고객 정보는 HTML이 아닌 일반 텍스트로 렌더링합니다.
