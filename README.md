# 어쩌다 농부 · 고구맙습니다

태안에서 어쩌다 농부가 된 부부의 이야기와 첫 고구마를 소개하는 한국어 원페이지 웹사이트입니다.

[현재 사이트 보기](https://eojjeoda-farmer-gogumap.silver-lynx-2417.chatgpt.site/)

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치·빌드 없이 실행하며, 스타일·스크립트·캐릭터 이미지를 HTML 한 파일에 포함했습니다.

로컬 서버를 사용하려면 저장소 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```sh
python3 -m http.server 8000
```

## 구성

- 브랜드 스토리 네 에피소드와 첨부 캐릭터
- 반응형 화면, 키보드 탐색, 입력 오류 안내
- 호풍미 혼합: 2kg 10,000원 / 5kg 20,000원
- 주문서 기본 선택 5kg, 배송비 3,500원
- 할인코드 `GOGUMA`: 주문당 2,000원 할인, 배송비 제외
- 주문서 금액 계산과 복사, 보관·품질 Q&A

주문서는 작성·복사하는 방식입니다. 자동 주문 접수, 결제, 메시지 전송은 연결되지 않았습니다.

## 편집

HTML에서 `const SITE_CONFIG`를 검색하면 가격, 배송비, 기본 상품과 할인코드를 변경할 수 있습니다. 에피소드와 Q&A는 해당 HTML 본문을 편집합니다.

- [상세 사용 안내](docs/사용안내.md)
- [캐릭터 이미지 작업 정보](docs/이미지작업정보.md)
- [편집용 투명 캐릭터](assets/mascot-clean.png)

`assets`의 이미지는 편집용 원본이며 웹사이트 실행에는 `index.html` 하나면 충분합니다.
