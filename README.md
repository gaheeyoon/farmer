# 어쩌다 농부 · 고구맙습니다

태안에서 어쩌다 농부가 된 부부의 이야기와 첫 고구마를 소개하는 한국어 원페이지 웹사이트입니다. Supabase에 주문을 저장하고 관리자 화면에서 재고와 배송을 관리합니다.

[판매 페이지](https://eojjeoda-farmer-gogumap.silver-lynx-2417.chatgpt.site/) · [농장 관리](https://eojjeoda-farmer-gogumap.silver-lynx-2417.chatgpt.site/admin.html)

## 실행

설치·빌드 없이 정적 서버에서 실행합니다. 이미지와 스타일은 HTML에 내장되어 있으며, 온라인 주문·로그인은 인터넷 연결이 필요합니다.

```sh
python3 -m http.server 8000
```

`http://localhost:8000`을 여세요. 배포할 때는 아래 실행 파일들과 `payment-config.js`를 같은 폴더에 함께 올립니다.

- `index.html`: 브랜드 이야기, 상품, 주문서
- `customer.js`: 상품 조회·할인 확인·주문 접수·기존 주문 조회
- `admin.html`, `admin.js`, `admin-gifts.js`: 관리자 로그인, 일반·선물 주문과 배송·재고 관리
- `admin-finance.js`, `admin-finance.css`: 관리자 전용 손익분석과 수입·지출 장부
- `farmer-api.js`: Supabase 통신과 관리자 세션
- `farmer-config.js`: 프로젝트 URL과 공개 publishable key
- `payment-config.js`: 고객에게 안내하는 입금용 은행·계좌·예금주 설정입니다. 주문 접수 후 입금 안내에 표시되며 배포 누락을 막기 위해 저장소에 포함합니다. `payment-config.example.js`는 다른 계좌로 설정할 때 참고하는 빈 예시입니다.

## 주문과 재고

- 호풍미 2kg 12,000원 / 5kg 22,000원, 기본 선택 5kg. 특·대·소·한입 사이즈의 혼합 구성입니다.
- 받는 분과 배송지를 최대 20곳까지 추가할 수 있습니다. 배송지마다 상품·수량을 선택합니다.
- 모든 배송지 무료배송, `GOGUMA`는 상품 금액의 10% 할인
- 주소 검색으로 우편번호·주소를 자동 입력하고, 연락처에는 하이픈을 자동으로 붙입니다.
- 가격·할인·수량은 서버에서 검증합니다.
- 입금 대기 → 입금 확인(배송 준비) → 배송 중 → 배송 완료. 입금 확인 시 중량 × 수량만큼 재고를 차감합니다.
- 관리자 상단의 단계별 건수를 누르면 해당 주문만 표시합니다. 같은 단계의 주문을 체크한 후 목록 위에서 다음 상태로 일괄 변경할 수 있습니다(현재 페이지 최대 50건). 필터·검색·페이지를 바꾸면 선택이 초기화됩니다.
- 배송 중으로 변경할 때 공통 택배사/배송 방법과 주문별 송장번호(선택)를 입력합니다. 배송 완료·취소된 주문은 일괄 선택에서 제외하며, 개별 취소는 주문 상세에서 처리합니다.
- 일괄 변경은 하나의 거래로 저장합니다. 재고 부족·오래된 주문 정보·잘못된 전환이 있으면 전체를 되돌립니다. 응답 유실 시 같은 요청으로 다시 확인하므로 재고가 중복 차감되지 않습니다.
- 배송 전 취소 시 확정 때 차감한 재고를 복구합니다. 접수만 된 주문은 재고를 차감하지 않습니다.
- 재고 입고·조정과 변경 사유, 발송 정보, 배송 완료 일시를 기록합니다.
- **선물 주문 등록**은 관리자만 사용할 수 있습니다. 받는 분을 최대 20곳까지 추가하고, 각 상품·수량·연락처·우편번호·주소를 입력합니다. 상품·배송비 청구액은 0원이며 등록과 동시에 재고를 차감하고 배송 준비로 저장합니다. 일반/선물 필터와 선물 표시로 구분하고 기존 일괄 배송 처리를 사용합니다. 배송 전 취소하면 재고가 복구됩니다.

주문 접수 후 설정한 입금 계좌와 총 입금액을 안내합니다. 입금까지 완료해야 주문이 완료되며, 관리자가 입금을 확인한 뒤 주문을 확정합니다. 자동 입금 확인, 택배사 자동 배송 추적, 문자·메일 알림은 연결하지 않았습니다.

**주문하기**에서 새 주문을 접수하고, **주문서 확인하기**에서 주문자 성함과 연락처로 기존 내역을 조회합니다. 상품·금액·입금/배송 상태를 카드로 표시하며, 받는 분 성함은 일부 가리고 연락처·주소는 반환하지 않습니다. 내역은 최신순 20건씩 표시합니다.

## 관리자와 개인정보

관리자는 Supabase Auth에서 이메일을 확인한 계정 중 비공개 허용 목록에 등록된 계정만 가능합니다. 비밀번호와 로그인 세션은 코드에 넣지 않습니다. 공개 키만으로 전체 주문 목록을 읽거나 재고를 변경할 수 없습니다.

공개 데이터베이스 테이블의 직접 접근은 모두 차단했습니다. 공개 RPC는 상품/금액 조회, 주문 접수, 이름·연락처가 일치하는 제한된 주문 조회를 허용하고, 관리자 RPC는 서버에서 이메일 인증과 허용 목록을 검사합니다. 고객 정보는 HTML이 아닌 일반 텍스트로 렌더링합니다.
