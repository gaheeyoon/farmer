# 고구맙습니다 운영 안내

## 관리자 화면

판매 페이지 하단의 **농부 관리실** 또는 `/admin.html`로 들어갑니다. 등록한 관리자 이메일과 직접 설정한 비밀번호로 로그인합니다. Supabase 대시보드 계정과 이 홈페이지의 관리자 계정은 별개입니다.

처음 사용하는 관리자라면 이메일과 새 비밀번호(12자 이상)를 입력하고 **처음 비밀번호 설정**을 누릅니다. 확인 메일의 링크로 이메일을 인증한 뒤 로그인합니다. 인증 화면이 다른 주소로 열려도 인증이 완료되었다면 관리자 페이지로 돌아와 로그인할 수 있습니다. 세션은 해당 탭의 메모리에서만 유지되어 새로고침 후에는 다시 로그인합니다.

## 하루의 주문 처리

1. **새로고침**을 눌러 최신 주문과 재고를 확인합니다.
2. 주문번호를 눌러 연락처, 배송지, 메모와 주문 금액을 확인합니다. 은행 입금 내역을 확인합니다.
3. **입금 확인 · 주문 확정**: 상품 중량 × 수량만큼 판매 가능 재고에서 차감합니다. 재고가 부족하면 확정되지 않습니다.
4. 택배사 또는 배송 방법과 송장번호를 입력하고 **발송 처리**합니다. 송장번호는 선택 사항입니다.
5. 실제 배송을 확인한 뒤 **배송 완료 처리**합니다. 완료 시각이 저장됩니다.

배송 전에는 취소할 수 있습니다. 확정된 주문을 취소하면 재고가 복구되고, 접수 상태에서 취소하면 재고는 바뀌지 않습니다. 발송 후 취소·반품은 자동 처리하지 않습니다.

접수는 재고 예약이 아닙니다. 여러 주문이 동시에 들어와도 확정 시 남은 재고를 확인하므로 마이너스 재고가 생기지 않습니다. 동시 편집으로 정보가 바뀌면 새로고침하도록 안내합니다.

## 재고

**재고 입고 · 조정**에서 입고/차감, kg, 변경 사유를 입력합니다. 소수 셋째 자리(1g)까지 기록할 수 있습니다. 관리자 화면에는 현재 판매 가능 kg와 최근 30건의 변경 이력이 표시됩니다. 주문에 따른 차감과 취소 복구도 이력에 남습니다.

## 고객 주문서

주문자 이름·연락처는 한 번만 입력합니다. 받는 분마다 상품·수량·성함·연락처·우편번호·주소·배송 메모를 작성하고, **받는 분 추가하기**로 최대 20곳까지 추가할 수 있습니다. 기본 상품은 각 배송지 모두 5kg입니다. **주문자와 같아요**는 입력한 주문자 이름과 연락처를 복사합니다.

**주소 검색**으로 [카카오 우편번호 서비스](https://postcode.map.kakao.com/guide)를 열면 우편번호와 기본 주소가 자동 입력됩니다. 상세 주소만 이어서 입력하세요. 검색 서비스 연결이 어려우면 **주소 검색이 어려우면 직접 입력**으로 우편번호와 주소를 적을 수 있습니다. 주소 검색은 버튼을 누를 때만 외부 서비스를 불러옵니다. 주문자와 받는 분 연락처는 숫자를 입력하면 하이픈이 붙습니다.

개인정보 수집·이용 체크는 기본 선택 상태이며, 해제하면 접수할 수 없습니다. **주문서 확인하기** 바로 위의 할인코드 칸에 코드를 적용합니다. **주문서 확인하기 → 주문 접수하기** 순서로 진행합니다. 실제 저장이 확인된 뒤에만 배송지별 주문번호와 접수 완료가 표시됩니다. 주문서 복사·내용 수정 버튼은 제거했습니다. 접수 전 입력란을 바꾸면 주문서를 다시 확인해야 합니다. 접수 후 **새 주문서 작성하기**를 누르면 같은 주문자가 추가 주문을 작성할 수 있습니다.

여러 배송지는 함께 저장되며 하나라도 입력 오류가 있으면 전체 접수가 중단됩니다. 관리실에서는 배송지별 주문으로 표시되므로 각각 확정·발송·배송 완료 처리합니다. 주문 상세의 주문 묶음 번호로 같은 접수에 속한 배송지를 확인할 수 있습니다. 기존 주문에는 우편번호가 없을 수 있습니다.

주문서 왼쪽에 카카오톡 주문 안내 문구를 넣었습니다. 채널이나 오픈채팅 링크는 연결하지 않았습니다.

연결이 끊겨 결과를 알 수 없는 경우에는 입력을 고정한 채 같은 주문을 다시 확인하도록 합니다. 같은 화면에서 재시도하면 주문이 중복 생성되지 않습니다. 이때 새로고침하거나 새 주문서를 만들지 말고 기존 버튼으로 재시도하세요.

접수 후에는 **입금까지 완료해야 주문이 완료됩니다**라는 안내와 입금액, 설정한 은행·계좌·예금주가 표시됩니다. 관리자 화면의 **입금 대기**는 접수 상태입니다. 은행 내역을 직접 확인한 뒤 **입금 확인 · 주문 확정**을 누르세요. 사이트는 입금을 자동 확인하지 않습니다. 주문 알림, 택배 추적도 자동 처리되지 않습니다. 수집한 고객 정보의 보관·파기 기준과 운영 연락처는 판매자가 운영 정책에 맞게 정해야 합니다.

## 상품과 할인

| 항목 | 내용 |
| --- | --- |
| 품종 / 크기 | 호풍미 / 혼합 |
| 가격 | 2kg 10,000원 / 5kg 20,000원 |
| 배송비 | 배송지 한 곳당 3,500원 |
| 할인코드 | GOGUMA · 상품 금액의 10% (배송비 제외) |

예: 5kg 1개에 할인 적용 시 20,000 − 2,000 + 3,500 = 21,500원입니다. 2kg 한 개는 1,000원, 5kg 한 개는 2,000원 할인되며 수량에 따라 할인액이 늘어납니다. 두 곳에 5kg 1개씩 보낼 때는 40,000 + 7,000 − 4,000 = 43,000원입니다. 기간과 고객별 횟수 제한은 없습니다.

할인액은 각 배송지의 상품 금액에 따라 기록합니다. 기존 접수 주문의 금액은 바꾸지 않습니다. 결제 및 환불 금액은 판매자가 확인해 안내합니다.

가격과 판매 여부는 Supabase `farmer_products`에서 수정합니다. 할인코드는 비공개 `farmer_private.discount_codes`의 `code`, `percent`, `amount`, `active`로 관리합니다. `GOGUMA`의 `percent`는 10, `amount`는 0입니다. `percent`가 0이면 기존 고정 금액 할인 방식이 사용됩니다. 화면의 계산은 서버 값을 사용하고 접수 때 다시 검증합니다. 상품명이 바뀌면 HTML의 기본 표시와 메타 설명도 함께 수정하세요. 배송비 정책 변경은 데이터베이스 함수와 화면 기본값을 함께 수정해야 합니다.
