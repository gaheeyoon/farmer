# 어쩌다 농부 · 고구맙습니다

## 바로 열기

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요하지 않습니다. 스타일, 이미지와 동작이 한 파일 안에 들어 있어 인터넷 없이도 열립니다. 글꼴은 기기의 한글 시스템 글꼴을 사용합니다.

## 반영한 상품 정보

| 항목 | 내용 |
| --- | --- |
| 품종 | 호풍미 |
| 크기 | 혼합 |
| 구성과 가격 | 2kg 10,000원 / 5kg 20,000원 |
| 배송비 | 3,500원 |

상품과 수량을 선택하면 상품 금액, 배송비, 총 주문 금액이 함께 표시됩니다. 현재 계산은 주문서 한 건에 배송비 3,500원을 한 번 더합니다. 예: 2kg 1개 13,500원, 5kg 3개 63,500원. 묶음·지역별 배송 조건이 달라지면 계산 기준도 수정해야 합니다.

## 주문서 이용 방법

1. 상품과 수량을 선택합니다. 기본 상품은 5kg입니다. 할인코드가 있다면 입력 후 **적용**을 누릅니다.
2. 주문자, 연락처, 배송 주소를 입력합니다. 상세 주소와 배송 메모는 선택 사항입니다.
3. 입력 내용을 확인하는 체크를 하고 **주문서 확인하기**를 누릅니다.
4. **주문서 복사**를 누른 뒤 판매자에게 직접 전달합니다.

현재 기능은 주문서 작성과 복사입니다. 자동 접수·결제·메시지 전송은 연결되지 않았으며, 판매자에게 보낼 구체적인 연락 채널도 아직 설정하지 않았습니다. 화면의 반복적인 데모 문구는 없앴고, 자동 전송되지 않는다는 안내를 폼 하단에 짧게 남겼습니다.

입력 정보는 서버나 브라우저 저장소에 저장하지 않습니다. 새로고침하면 입력이 초기화됩니다. 복사 버튼을 누르면 개인정보를 포함한 주문서가 기기의 클립보드에 복사됩니다. 자동 완성은 브라우저 설정에 따릅니다. 복사 권한이 없을 때는 텍스트를 선택해 직접 복사할 수 있습니다. 입력이 바뀌면 이전 주문서의 복사를 막고 다시 확인하도록 안내합니다.

## 할인코드

**GOGUMA**를 입력하면 주문당 **2,000원**이 할인됩니다. 영문 대소문자와 앞뒤 공백은 구분하지 않습니다. 수량이 여러 개여도 한 번만 적용하며, 배송비 3,500원은 할인 대상에서 제외합니다. 상품 금액보다 큰 할인은 상품 금액까지만 적용합니다.

5kg 1개 기준: 20,000원 − 2,000원 + 배송비 3,500원 = **21,500원**.

할인 적용 후 코드 입력을 바꾸면 할인이 해제되므로 다시 적용해야 합니다. **해제** 버튼으로 취소할 수도 있습니다. 복사할 주문서에 할인코드와 할인 금액이 포함됩니다.

현재 할인코드의 기간·고객별 사용 횟수 제한은 없습니다. 코드 설정은 HTML 안에 있으므로 비밀 키가 아닙니다. 실제 결제 서비스를 연결할 때는 주문을 받는 쪽에서도 코드와 금액을 검증해야 합니다.

## 쉽게 수정하기

텍스트 편집기에서 HTML의 `const SITE_CONFIG`를 검색하세요.

| 설정 | 용도 |
| --- | --- |
| `brand`, `productName` | 주문서에 표시할 브랜드와 상품명 |
| `variety`, `size` | 품종, 크기 |
| `products` | 상품별 `id`, `weight`, `price`, `unit` |
| `shippingFee` | 주문서 한 건의 배송비 |
| `defaultProductId` | 기본으로 선택할 상품 ID. 현재 `hopungmi-5kg` |
| `discountCodes` | `code`: 코드명, `amount`: 주문당 할인액(원), `enabled`: 사용 여부 |
| `maxQuantity` | 최대 입력 수량. 현재 99는 입력 한도이며 재고 수량이 아닙니다. |
| `contactGuide` | 확인된 주문 전달 방법 안내 |

`price`와 `shippingFee`는 따옴표·쉼표·원 표시 없이 숫자로 적습니다. 예: `price: 10000`. 수정 내용은 상품 안내 표, 선택 항목, 금액 계산과 복사할 주문서에 반영됩니다. 자바스크립트를 끈 환경에서도 새 안내가 보이게 하려면 HTML에 있는 기본 상품 표와 선택 항목도 함께 수정하세요.

브랜드 이야기와 Q&A는 해당 본문을 직접 편집합니다. 색상은 위쪽 `:root`의 `--cream`, `--purple`, `--brown` 등에서 변경합니다. 상단 로고는 기존 둥근 보라색 캐릭터입니다. 본문 고구마 그림은 첨부한 일러스트를 사용하며 에피소드 04는 외곽을 정리한 `mascot-clean.png`를 내장했습니다.

## Q&A 작성 기준

첨부 이미지의 다섯 주제(보관·단맛·껍질/모양·싹·손상)를 바탕으로 문장을 새로 썼습니다. 다른 업체의 3일 접수 기한, 톡톡 채널, 부분 환불 조건은 적용하지 않았습니다. 손상 문의는 사진으로 상태를 확인한 뒤 처리 방법을 안내하는 내용입니다.

보관 안내는 [농촌진흥청의 과일·채소 보관 안내](https://rda.go.kr/board/board.do?boardId=farmprmninfo&currPage=11&dataNo=100000813032&mode=updateCnt&prgId=day_farmprmninfoEntry&searchEDate=&searchKey=&searchOrgDeptKey=allOrgDept&searchOrgDeptVal=&searchSDate=&searchVal=)의 고구마 저온 민감성 설명도 참고해 확인했습니다.

## 확인한 범위

- Chrome 320 / 390 / 768 / 1024 / 1440px에서 가로 넘침 없음
- 데스크톱·모바일 상품 정보와 주문서 화면 확인
- 2kg·5kg 가격, 수량 변경, 배송비를 포함한 합계와 주문서 금액 일치
- 필수 입력, 전화번호, 0·소수·한도 초과 수량, 확인 체크 검사
- 할인코드의 대소문자/공백 처리, 잘못된 코드, 중복 적용 방지, 수량 변경에도 2,000원 정액 할인
- 할인 해제/수정 시 재계산, 5kg 기본 선택과 새로고침·뒤로 가기 상태 초기화
- 할인 내역을 포함한 주문서 복사와 클립보드 일치, 입력 변경 시 이전 주문서 복사 차단
- 주문서 작성 중 네트워크 요청 없음, 새로고침 후 정보 초기화
- Q&A 키보드 열기, 오류 항목으로 초점 이동, 동작 줄이기 설정 지원

Safari·Firefox 실기기와 스크린리더 조합은 별도 검증하지 않았습니다. 자동 접수나 결제를 운영하려면 주문 서버 또는 외부 주문 서비스 연결이 추가로 필요합니다. `SITE_CONFIG` 수정만으로 전송 기능이 활성화되지는 않습니다.
